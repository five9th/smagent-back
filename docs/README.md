# docs

Platform-facing documents required for app review / API access, one folder per platform.

```
docs/
  platforms/
    facebook/   # privacy-policy.html (host publicly, set as Privacy Policy URL in app dashboard)
    reddit/
```

Notes:
- Each platform folder holds the documents that platform's review process requires
  (privacy policy, terms of service, data deletion instructions, etc.).
- These files must be published at a public HTTPS URL before submitting an app for review.
